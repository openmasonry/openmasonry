# raw/: source clips

The external sources the wiki is built from, one file per source.

- Each source is saved once, as `raw/sources/<slug>.md`. Local images go in `raw/assets/`.
- Clips are not edited after they are saved. Corrections and commentary go in the wiki.
- Each clip has a summary page at `wiki/sources/<slug>.md`.

[wiki/README.md](../wiki/README.md) explains how to add a source.
